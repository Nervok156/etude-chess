# Этюд — шахматный тренажёр

Веб-приложение для тренировки тактических навыков в шахматах:
117 задач, игра против Stockfish, онлайн-мультиплеер 1 на 1,
статистика прогресса.

**Демо:** https://web-production-05bd8.up.railway.app

---

## Возможности

- **Каталог из 117 задач** — мат в 1, мат в 2, вилка, связка,
  вскрытое нападение, последняя горизонталь.
- **Тренажёр** — проверка ходов по эталонному решению,
  подсказки, таймер, автоплей соперника в многоходовых задачах.
- **Игра против Stockfish WASM** — 8 уровней сложности
  (800–2850 Elo), оценка позиции в реальном времени.
- **Онлайн 1 на 1** — комнаты по коду, чат, часы, реванш.
- **Статистика** — точность решений, среднее время, прогресс по темам.
- **Адаптивность** — работает на экранах от 320px.

## Быстрый старт

```bash
git clone https://github.com/Nervok156/etude-chess.git
cd etude-chess
npm install
npm run dev
```

Приложение откроется на **http://localhost:3000**.

**Требуется:** Node.js 20+.
