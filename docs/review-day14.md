## Замечания

### Замечание 1. В user-guide нет скриншотов

- **Где:** `docs/user-guide.md`, раздел 3 «Основные функции»
- **Проблема:** текстовые описания без визуальных примеров.
  Пользователю сложнее ориентироваться.
- **Серьёзность:** средняя.
- **Решение:** добавить 3–5 скриншотов ключевых экранов
  (каталог, тренажёр, игра с ботом, мультиплеер, статистика).
  Отложено — скриншоты есть в `docs/screenshots/`, но
  не встроены в руководство.

### Замечание 2. В install-guide нет раздела про Docker

- **Где:** `docs/install-guide.md`, раздел 4 «Развёртывание»
- **Проблема:** нет инструкции для Docker, что полезно для
  production-развёртывания.
- **Серьёзность:** низкая.
- **Решение:** раздел добавлен с пометкой «в roadmap».

### Замечание 3. Ссылки в README на docs/*.md работают

- **Проверено:** все ссылки ведут на существующие файлы.
- **Статус:** ✅

### Замечание 4. Команды в install-guide корректны

- **Проверено:** `git clone`, `npm install`, `npm run dev` —
  команды рабочие, проверены локально.
- **Статус:** ✅

### Замечание 5. Единый стиль оформления

- **Проверено:** везде один стиль: заголовки `##`,
  блоки кода с языком, таблицы.
