## Слайд 2. Проблема и актуальность (40 сек)

«Шахматисты-любители часто знают теорию, но проигрывают из-за
недостатка тактической практики. Решение задач — самый эффективный
способ развить тактическое зрение.

Существующие решения — Lichess, Chess.com, ChessTempo — мощные,
но перегружены функциями и не всегда удобны для регулярной
тренировки. Многие ориентированы на англоязычную аудиторию.

**Проблема:** нужен лёгкий русскоязычный тренажёр с понятным
интерфейсом, без регистрации и сложных настроек.

**Решение:** приложение «Этюд» — каталог задач + тренажёр +
игра с движком + онлайн-мультиплеер.»

---

## Слайд 3. Цель и задачи (30 сек)

«**Цель** — создать веб-приложение для тренировки тактических
навыков в шахматах с полным циклом: от решения задачи до игры
против движка и другого игрока.

**Задачи:**
1. Реализовать каталог из 100+ задач с фильтрами.
2. Сделать тренажёр с проверкой ходов и подсказками.
3. Интегрировать шахматный движок Stockfish.
4. Реализовать онлайн-мультиплеер.
5. Обеспечить покрытие тестами ≥70% и чистую архитектуру.»

## Слайд 4. Целевая аудитория (30 сек)

«Приложение рассчитано на три группы:

**Первая** — шахматисты-любители с рейтингом 800–1600, которые
хотят систематически тренировать тактику.

**Вторая** — студенты и школьники, изучающие шахматы.
Им важен понятный интерфейс и мотивация через статистику.

**Третья** — преподаватели шахмат для демонстрации типовых
позиций и тактических приёмов на занятиях.

Регистрация не требуется — прогресс хранится в браузере.»

## Слайд 5. Функциональность (60 сек)

«Что умеет система:

**Каталог задач** — 117 позиций с фильтрами по теме и сложности.
Темы: мат в 1, мат в 2, вилка, связка, вскрытое нападение,
последняя горизонталь.

**Тренажёр** — проверка ходов по эталонному решению. Если задача
многоходовая — соперник автоматически отвечает. Есть подсказки,
таймер, история ходов.

**Игра с ботом** — Stockfish WASM в Web Worker. Восемь уровней
сложности, от 800 до 2850 Elo. Оценка позиции в реальном времени.

**Онлайн 1 на 1** — комнаты по коду, чат, таймеры, реванш, сдача.

**Статистика** — точность решений, среднее время, прогресс по темам.

Всё это доступно без регистрации.»

## Слайд 7. Архитектура и стек (50 сек)

«Проект построен на современном стеке:

**Фронтенд** — React 19 с TypeScript, сборка через Vite 8.
Стилизация — Tailwind CSS 4.

**Шахматная логика** — библиотека chess.js. Она отвечает
за правила, генерацию ходов и валидацию.

**Движок** — Stockfish, скомпилированный в WebAssembly.
Работает в Web Worker, не блокирует интерфейс.
На случай таймаута есть собственный fallback с альфа-бета
отсечением.

**Бэкенд** — Express и WebSocket для мультиплеера.

**Хостинг** — Railway. CI — GitHub Actions.»

---

## Слайд 8. Диаграмма компонентов (40 сек)

«Архитектура модульная. Точка входа — App.tsx. Он владеет
глобальным состоянием и маршрутизацией между экранами.

Экраны — каталог, тренажёр, игра с ботом, мультиплеер,
статистика — не знают друг о друге напрямую, только через App.

Общие UI-компоненты: доска Chessboard переиспользуется
в трёх экранах, фигуры отрисовываются SVG-спрайтами Cburnett.

Утилиты: storage — работа с прогрессом, stockfish — обёртка
движка, exceptions — классы исключений.»
