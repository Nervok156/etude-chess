## Стратегия тестирования

**Что тестируем в первую очередь:**
1. Критические функции — проверка ходов, сохранение прогресса, движок.
2. Интеграция модулей — работа каталога → тренажёра → статистики.
3. Устойчивость к ошибкам — битый localStorage, обрыв WebSocket.

**Что не тестируем (и почему):**
- CSS-анимации и переходы — визуальные, не влияют на логику.
- Стилистика компонентов — проверяется визуально.
- Конкретные формулировки текста в UI — меняются часто, не критичны.

**Целевое покрытие:** 70% критических функций.
**Фактическое:** ~80% (13 функций покрыто unit-тестами из 16).
