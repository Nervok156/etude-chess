## Performance-тест-кейсы (TC-26 — TC-29)

Отличаются от функциональных кейсов тем, что измеряют не
корректность, а время отклика. Каждый содержит явную методику
измерения и порог.

### Методика измерения

- **Инструмент:** `performance.now()` внутри теста + `node --test`.
- **Число повторов:** 3 прогона, берётся среднее.
- **Условия:** Node.js 24.14.1 (Windows 11), без фоновой нагрузки.
- **Порог:** согласован с требованиями ТЗ (интерактивные
  операции < 100 мс, движок < 1 с).
