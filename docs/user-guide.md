# Руководство пользователя

## «Этюд» — шахматный тренажёр

**Версия:** 1.0
**Дата:** 06.10.2026
**Демо:** https://web-production-05bd8.up.railway.app

---

## 1. Введение

«Этюд» — веб-приложение для тренировки тактических навыков
в шахматах. Пользователь решает задачи с готовыми позициями,
играет против движка Stockfish и с другими людьми через интернет.

**Для кого:**
- Шахматисты-любители (рейтинг 800–1600), желающие подтянуть тактику.
- Студенты и школьники, изучающие шахматы.
- Преподаватели шахмат для демонстрации типовых позиций.

---

## 2. Начало работы

### 2.1. Открытие приложения

Приложение доступно онлайн, без установки:

1. Откройте браузер (Chrome, Firefox, Edge последних версий).
2. Перейдите по ссылке: https://web-production-05bd8.up.railway.app
3. Дождитесь загрузки (обычно 1–2 секунды).

Для локального запуска см. `docs/install-guide.md`.

### 2.2. Регистрация / вход

**Регистрация не требуется.** Прогресс сохраняется в браузере
пользователя (localStorage) и привязан к устройству. При смене
устройства прогресс начинается заново.

## 3. Основные функции

### 3.1. Каталог задач

Раздел **«Каталог»** — стартовый экран приложения.

1. В верхнем меню выберите **«Каталог»**.
2. По умолчанию отображаются все **117 задач**.
3. Фильтры:
   - по теме («Мат в 1», «Мат в 2», «Вилка», «Связка» и др.);
   - по сложности («Лёгкая», «Средняя», «Сложная»);
   - по статусу («Нерешённые», «Решённые»);
   - поиск по номеру задачи или теме.
4. Клик по карточке задачи открывает экран решения.

### 3.2. Решение задачи

1. Откройте задачу из каталога.
2. На доске сделайте ход — перетащите фигуру или кликните
   сначала по фигуре, потом по клетке назначения.
3. Если ход верный:
   - прозвучит звук хода;
   - в многоходовых задачах соперник автоматически ответит;
   - при завершении решения появится сообщение «Правильно!».
4. Если ход неверный — появится сообщение об ошибке,
   счётчик попыток увеличится.
5. Доступны кнопки:
   - **«Подсказка»** — показывает текст и подсвечивает поле;
   - **«Начать заново»** — сбрасывает задачу;
   - **«Следующая»** — переход к следующей задаче в каталоге.
6. Счётчик времени в правом верхнем углу считает секунды
   до момента решения задачи.

### 3.3. Игра против бота

Раздел **«Игра с ботом»**.

1. Выберите уровень сложности (1–8, от 800 до 2850 Elo).
2. Выберите цвет: белые или чёрные.
3. Нажмите **«Новая игра»**.
4. Ходите на доске — бот отвечает в течение 1–3 секунд.
5. Панель оценки позиции (слева от доски) показывает, у кого
   преимущество, по мнению Stockfish.
6. Часы идут у активного игрока. Кнопка **«Сдаться»** завершает партию.
7. После окончания — кнопка **«Сыграть снова»**.

### 3.4. Онлайн-мультиплеер (1 на 1)

Раздел **«Онлайн 1 на 1»**.

**Создать партию:**
1. Введите имя, выберите цвет, время на партию (3–15 минут).
2. Нажмите **«Создать комнату»**.
3. Скопируйте ссылку с кодом комнаты и отправьте сопернику.

**Присоединиться:**
1. Откройте ссылку, полученную от соперника, или введите код
   комнаты вручную.
2. Нажмите **«Войти»**.

**Во время партии доступны:**
- часы с таймером;
- чат с соперником;
- кнопки «Сдаться» и «Реванш»;
- история ходов в правой панели.

### 3.5. Статистика прогресса

Раздел **«Статистика»** показывает:
- сколько задач решено из общего числа;
- точность решений (процент задач, решённых с первой попытки);
- среднее время на задачу;
- прогресс по темам тактики;
- прогресс по уровням сложности.

Кнопка **«Сбросить прогресс»** внизу страницы удаляет
все сохранённые результаты.

## 4. Роли пользователей

### 4.1. Гость (по умолчанию)

Все пользователи приложения — гости без регистрации.
Доступны все функции: каталог, тренажёр, игра с ботом,
мультиплеер, статистика.

### 4.2. Игрок в мультиплеере

Пользователь, создавший или присоединившийся к комнате
в разделе «Онлайн 1 на 1». Дополнительно к базовым функциям
получает: чат с соперником, возможность сдачи партии, реванш.

## 5. Часто задаваемые вопросы

**В: Нужна ли регистрация?**
О: Нет. Прогресс сохраняется в браузере. Чтобы не потерять
его — не очищайте данные сайта.

**В: Что делать, если бот долго думает?**
О: На уровнях 6–8 движок может задуматься на 2–3 секунды.
Если превышает 5 секунд — используется резервный алгоритм,
ход всё равно будет сделан.

**В: Почему в мультиплеере соперник не подключается?**
О: Убедитесь, что отправили ссылку с кодом комнаты. Если
соперник открыл просто главную страницу — он не попадёт в вашу
партию.

**В: Можно ли решать задачи с телефона?**
О: Да. Интерфейс адаптирован под экраны от 320px.

**В: Как экспортировать прогресс?**
О: Пока нельзя. Экспорт в CSV — в планах разработки.
