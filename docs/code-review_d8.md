## Замечания

### Замечание 1. Ошибка в сводной таблице приоритетов

- **Где:** `docs/test-cases.md`, раздел «Сводка».
- **Проблема:** указано «Высокий: 12, Средний: 10, Низкий: 2»,
  но фактическое перечисление кейсов даёт 13 / 11 / 1.
- **Серьёзность:** средняя (искажает статистику покрытия по приоритетам).
- **Исправлено:** таблица приведена к фактическому распределению:
  высокий — 13, средний — 11, низкий — 1.

### Замечание 2. Субъективные ожидаемые результаты

- **Где:** TC-15 («бот отвечает ... сильным ходом»), TC-12
  («графики соответствуют решённым задачам»).
- **Проблема:** формулировки «сильный ход», «соответствуют»
  невозможно проверить однозначно. Нет метрики.
- **Серьёзность:** высокая (тест-кейс становится нефальсифицируемым).
- **Исправлено:**
  - TC-15: заменено на «бот выполняет легальный ход не позднее
    3 с, состояние партии валидно по chess.js».
  - TC-12: заменено на «для каждой темы число решённых в UI
    равно числу решённых в localStorage».

### Замечание 3. Performance-проверки размазаны по функциональным

- **Где:** TC-07, TC-14, TC-15, TC-21.
- **Проблема:** пороги времени указаны как ожидаемый результат,
  но без методики измерения (нет числа повторов, условий,
  измеримого инструмента).
- **Серьёзность:** средняя (результат нельзя воспроизвести).
- **Исправлено:** добавлен отдельный раздел
  «Performance-тест-кейсы (TC-26 — TC-29)» с методикой измерения,
  числом повторов и явными порогами.

### Замечание 4. Не хватает негативных кейсов на сервер

- **Где:** `docs/test-cases.md`, раздел мультиплеера.
- **Проблема:** есть TC-21..TC-23 про успешные сценарии, но нет
  кейса на попытку клиента отправить нелегальный ход на сервер
  (нарушение целостности партии).
- **Серьёзность:** низкая (есть серверная валидация, но она
  не покрыта отдельным кейсом).
- **Исправлено:** добавлен TC-30 — отправка нелегального хода
  через DevTools, ожидается отклонение сервером.

### Замечание 5. Не указаны точные версии окружения

- **Где:** `docs/test-cases.md`, общая часть.
- **Проблема:** непонятно, на какой версии Node.js, браузера
  и chess.js проводились измерения.
- **Серьёзность:** низкая (не влияет на логику, но влияет
  на воспроизводимость).
- **Исправлено:** добавлен раздел «Окружение тестирования» с
  версиями Node, браузера, ОС.
