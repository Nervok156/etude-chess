# Changelog

Все значимые изменения проекта «Этюд» документируются в этом файле.

## [1.0.0] - 2026-10-05

### Добавлено
- Каталог из 117 шахматных задач с фильтрами по теме и сложности.
- Тренажёр с проверкой ходов по эталонному решению.
- Поддержка многоходовых задач (мат в 2) с автоплеем соперника.
- Подсказки: текст + подсветка поля.
- Таймер решения задачи.
- Игра против Stockfish WASM (8 уровней, 800–2850 Elo).
- Fallback-движок с альфа-бета отсечением (при недоступности Stockfish).
- Онлайн-мультиплеер через WebSocket: комнаты, чат, реванш, сдача.
- Статистика прогресса: точность, среднее время, разбивка по темам.
- Процедурные звуки ходов и взятий (Web Audio API).
- Система классов исключений (`exceptions.ts`, `ErrorToast.tsx`).
- Глобальный обработчик ошибок с тостами.
- CI на GitHub Actions: прогон тестов и покрытия на каждый push.

### Изменено
- Рефакторинг по итогам инспекции кода (день 11):
  - магические числа вынесены в константы (`MS_PER_SEC`, `MATE_SCORE`, `WORST_SCORE`);
  - устранено дублирование `formatTime` в трёх компонентах;
  - добавлен JSDoc к публичным функциям `server.ts`.
- Обновлены метрики качества (день 12).

### Исправлено
- BR-01: скролл страницы при ходе в мультиплеере.
- BR-02: таймер мультиплеера обновлялся только после хода.
- BR-03: `AudioContext` не запускался при первом ходе.
- BR-04: проверка `window` вместо `localStorage` в `storage.ts`.

### Технологии
- React 19 + TypeScript + Vite 8.
- chess.js для правил шахмат.
- Stockfish WASM в Web Worker.
- Express + WebSocket (ws) для мультиплеера.
- Tailwind CSS 4.
- Node.js test runner + tsx для тестов (35 штук, покрытие 99.38%).
- Хостинг: Railway (фронт + сервер).
- CI: GitHub Actions.
